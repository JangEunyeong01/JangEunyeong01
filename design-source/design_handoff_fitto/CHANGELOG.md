# 최근 변경사항 (클로드 코드에 전달)

이 문서는 디자인이 처음 넘어간 뒤 확정·변경된 내용만 모은 것입니다. 상세 명세는 `README.md`가 최신 기준입니다.

## 1. 확정된 기본 안 (중요 — 이전 문서의 A 조합을 덮어씁니다)
| 항목 | 이전 안내 | **확정** |
|---|---|---|
| 홈 카드 레이아웃 | A 스택 | **B 히어로** — 칼로리 전폭 → 물·걸음 반폭 2열 → 활동 → 운동 → 주간 → 생리 |
| 물 카드 인터랙션 | A 5단계 게이지 | **B 컵** — 86×112 컵을 탭하면 250ml씩 차오르고 수면에 물결 애니메이션, 퍼센트 표시 |
| 헤더 그라데이션 | A 페이드 | A 페이드 (변경 없음) |
| 탭바 | B 4탭 + 중앙 FAB | B 4탭 + 중앙 FAB (변경 없음) |

프로토타입 파일도 이 조합이 기본값으로 열리도록 수정했습니다. A안·C안은 구현할 필요 없습니다.

물 카드는 B(컵)로 가더라도 **세로 드래그 증감**(위로 끌면 증가, 아래로 끌면 감소, 4px당 50ml, 50ml 스냅)은 그대로 유지합니다.

## 2. 온보딩 확장: 5단계 → 9단계
기본 정보 입력이 추가되어 목표 칼로리·물 목표를 실제로 계산합니다.

1. 인트로
2. **기본 정보** — 이름 / 성별(여성·남성·선택 안 함) / 나이 / 키 / 몸무게
3. **활동량** 5단계
4. **목표** 6종 — 체중 감량 · 체중 증가 · 체중 유지 · 건강 관리 · 근력 강화 · 체력 증진
5. **건강 상태** — 태그 8종 + 직접 입력
6. **식단 취향** — 한식·양식·일식·중식 등 8종 + 직접 입력
7. **못 먹는 음식/알레르기** — 견과류·유제품·해산물·갑각류 등 10종 + 직접 입력
8. **피또 성격** 3종
9. **완료** — 계산된 목표 + 입력 요약

5·6·7단계는 동일한 "태그 + 직접 입력" 컴포넌트입니다: 2열 태그 그리드 → 직접 입력 + 추가 버튼 → 선택된 항목 칩(× 제거) → `해당사항 없음` 링크. **직접 입력한 값도 선택 칩으로 들어가고 저장됩니다.**

계산식(Mifflin-St Jeor + 활동 계수 + 목표 보정, 물 = 체중×33ml)은 README "1. 온보딩" 마지막에 코드 블록으로 있습니다. 완료 시 홈 대시보드 목표치와 프로필에 반영됩니다.

## 3. 그 외 확정 사항
- **카드 빈 공간 금지**: 같은 행 카드는 높이를 맞추고(`align-items: stretch`), 걸음수 카드 하단에는 최근 7일 미니 막대 + `최근 7일 · 평균 7,789` 캡션이 들어갑니다.
- **월간 기간 선택**: 물·걸음 상세의 월간 탭에 기간 바(‹ › 월 이동, 한 달/최근 3개월/최근 6개월/직접 선택, 최대 12개월).
- **레시피 재료 직접 입력**: 자주 쓰는 재료 칩 외에 재료명 + 100g당 kcal(필수) + 탄·단·지(선택)로 직접 추가. 추가한 재료는 칩 목록에 남아 재사용됩니다.
- **음식 검색**: 결과 행마다 `추가` 버튼(알레르기 항목은 `제외` 회색 + 경고 토스트), 검색 입력 우측에 ✕ 지우기 버튼.
- **홈 카드 순서**: 롱프레스 550ms 또는 설정에서 열리는 시트에서 ↑↓ 이동 + 표시/숨김 + 기본값 복원. 순서·숨김은 영구 저장.
- **식단 분석 / 알림 / 프로필 / 리포트** 화면이 추가되었습니다(README 6·9·11장).
